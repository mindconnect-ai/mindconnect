- **admin UI:** **a link that opens a screen with a dialog keeps the menu.**
  A page that opens a dialog as it loads — an Office file link from the chat
  lands on its folder with the file open — was sent without the app shell,
  and once the dialog was closed the screen stood there without menu and
  header. Every page with content is now wrapped in the layout, dialogs or
  not; a response that only brings dialogs still goes out as it is.
