- **admin-ui:** **three VS Code themes in the theme picker.** *VS Code Dark*,
  *VS Code Light* and *VS Code High Contrast* give the Admin UI the editor's
  Dark Modern, Light Modern and High Contrast look — and its density: 13px
  throughout, 26px buttons and fields, a 36px header, quiet text-style
  *Delete* buttons instead of red blocks. The themes read VS Code's own colour
  variables (`--vscode-*`), so the Admin UI embedded in the VS Code extension
  can follow whatever theme the editor wears. Set one as the installation's
  default with `mindconnect.branding.theme: vscode-dark`.
