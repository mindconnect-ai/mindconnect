- **agents:** **tools can be added by the group.** The agent's Tools table
  has **Add a group…** beside Add Tool, and the profile's My tools picker
  offers the same sets: a whole group (the five email tools), a subgroup
  within it (one MCP server), everything one connection brings (the thirteen
  Microsoft tools), or several single tools at once. A set expands into its
  tools right there — each lands as its own row, so Remove takes one out
  again — and names already present are left as they are.
