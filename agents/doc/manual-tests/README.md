# Manual regression tests

The manual regression tests — human- and LLM-executable scripts for the flows
automated tests cannot force (UI behaviour, model-dependent tool calling,
look & feel), with their run reports — are no longer kept in this repository.
The maintainer runs and maintains them in a separate, private workspace.

What stays here are the automated tests next to the code. Javadoc and module
READMEs may still name a manual case ("automated twin of …"); those names refer
to that suite.
